# Agent Room — エージェント可視化プロトタイプ

oVice / Gather のような2Dルームで、AIエージェントやサブエージェントたちを
ドラクエ風ドット絵キャラクターとして可視化する、単一HTMLファイルの試作です。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・サーバー不要）。

- メインエージェント「おちゃ」と、サブエージェントたちが部屋を歩き回ります
- 各キャラの頭上の吹き出しに「今やっている仕事」と状態が出ます
- キャラをクリックすると、担当タスクの詳細（状態・進捗）が見られます
- 家具（ソファ・お風呂・筋トレコーナー・食事テーブルなど）に近づくと、
  スマホ操作・食事・コーヒー・お風呂などの日常アクションをします
- 移動は家具や他のキャラを避ける経路探索で、机を横断したり重なったりしません

## 他の Muse が使うとき

これは表示のシミュレーションを含むプロトタイプです。自分のエージェント構成に
合わせて使う場合は、`index.html` 内のエージェント／タスクのデータ定義を
差し替えてください（メインエージェントの仕事リスト、サブエージェントの名前・
タスク・状態）。実エージェントの状態と連動させる場合は、そのデータ定義を
外部の状態データで置き換えるのが想定された拡張ポイントです。

## 共通化設定（他のAIも可視化する）

Claude Code / ChatGPT / Codex など、Muse 以外のAIも同じ部屋に
キャラクターとして並べられるよう、共通設定を用意しています。

- `agent-room.config.json` — エージェント定義（名前・種別・provider・色）と、
  「今なにをしているか」の報告フォーマットの共通設定
- `SPEC.md` — 共通化仕様。エージェント定義と報告フォーマットの意味、
  ツール別（Claude Code / Codex / ChatGPT）のつなぎ方

どのAIでも、報告フォーマットに沿って自分の状態を報告できれば、
同じ部屋・同じ見た目で可視化できます。

## localhost版（実データでリアルタイム表示）

`local/` フォルダに、自分のPCやミニPCで動かす実データ版が入っています。
見た目は静的版のままに、小さなサーバー（Node・依存なし）が報告を受けて、
部屋が2秒ごとに最新状態へ更新されます。Claude Code のフックから報告を
送る設定例も同梱しています。詳しくは `local/README.md` を参照してください。

```bash
node local/server.mjs   # → http://localhost:4310
```

## 技術メモ

- 単一HTML（CSS / JavaScript インライン）、外部依存なし
- ドット絵はピクセルマップ方式のスプライト描画（16×18px ちびキャラ、
  歩行2フレーム＋腕振り・体の揺れ）
- UIはドラクエ風「黒窓＋白フチ」のコマンドウィンドウ
